# 美术、镜头与资产约束

## 审美基准
- 轻像素风，温暖自然色的水泥车库，暗蓝灰色左栏，亮色金币/升级按钮；以参考概念图为氛围参考，而不是直接复刻商业作品画面。
- 固定2D构图：背景为整体车库示意；玩家面对主罐的第一人称交互是“鼠标鞋子”，不是第三人称完整腿。
- 罐子和鞋子需要透明背景独立PNG；五阶段罐压扁帧；统一相同画布尺寸、锚点和光源方向，避免切换抖动。
- 第一版暂时使用提供的原创占位素材：罐红/蓝/金的5帧 PNG、鼠标鞋默认/踩踏 PNG、floor tile、coin icon。渲染采用 nearest filter。建议将贴图导入后单独设置锚点，并对鼠标脚尖补偿 hotspot。

## 背景
- 已有概念图 `assets/references/garage_gameplay_reference.png` 仅供比例、氛围、层次参考；它含有UI/装饰不能当作纯背景导入，否则可交互物与贴图错位。
- 可在Godot使用绘制多边形、低分辨率砖块/水泥 tile、工具架/回收箱占位分层构建场景。可以把 `assets/placeholders/concrete_tile.png` 作为重复图案，用自己的简单结构叠出车库。
- 操作区至少保留屏幕中部500×400px不被杂物遮挡；右上角独立自动线不遮挡主罐。

## 动画表现
- 鞋子光标主帧姿态略微倾斜、脚尖是真实判定位置。每次踩击做0.08s快速下压和0.1s恢复，避免大幅飞进飞出的第三人称镜头。
- 罐子：形状变化是核心。轻微震动、脚印、小铝屑、撞击闪线、金币数字短暂飘起即可。
- 稀有金罐：少量星点和额外音效；禁止高频闪光。

## 不做
- 不直接抽取商业游戏图片当作可执行素材。
- 不做真人脚、袜子/小腿，或大角色从画面上方踩下来。
- 不做实时3D造型和物理软体破坏。
