## 已实现

- 鞋→机械义手→动力锤→高速电钻；共享冷却，材质亲和、锤的有限近邻震荡、电钻连续锁定增伤。
- 九类废品、每类五阶段：旧红/蓝/金罐+纸团、瓶、键盘、风扇、电脑、洗衣机。尺寸与命中/软接触同步。
- 传送门深度/品质、供货提速；初始1秒/件，1→.8→.6→.4→.25秒；落地弹跳滚动，未拆完永久堆积。
- 扫描弱点、连拆充能、F狂拆、R磁力归拢；垃圾暴雨/金价日/神秘包裹事件。
- 独立自动回收线不删除地面物；九格图鉴与回收数、可选小破剧情、义肢安装、工坊完成面板。
- 目标同时满足“拥有电钻、深度II、回收洗衣机”；完成后可继续经营。
- 暂停/失焦暂停、音乐/静音/减弱特效、确认重置、隔离v3存档与经典v1/v2导入。
- 原创工坊/新增垃圾/工具图标、合成音效与循环音乐。没有付费外部资产。

## 本轮验证与边界

完整实跑证据见 `YARD_TEST_REPORT.md`，包括旧353项、新97状态+21场景+6输入检查、三种操作频率成长模拟、21项Python检查及7张原生2K实际渲染图。
策略模拟采用精准选目标与弱点，不是人工体验；约7.5–11.3模拟分钟完成本切片，未证明20–30分钟真人目标。
完整五章、工业/异界场景、最终义肢与3–5小时内容仍未实现。
Windows新版本未打包、未实机验证；旧v1.1 ZIP不包含新工坊。Mac/Windows系统字体可能有差异。
伪物理允许堆叠；不自动删废品，超长囤积的绘制/命中/保存耗时仍会增加。没有专用game-dev遥测证据。
