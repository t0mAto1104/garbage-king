# Demo 验收测试（Codex / 真人测试）

## 核心逻辑自动化测试
- `stomp_damage`: 初始伤害1；HP3初始红罐3次完成；脚力LV1时2次，脚力LV2时1次；HP不可为负。
- `stage_mapping`: 完整→轻凹→折痕→接近平→全扁，所有阶段图片存在；逐次受击允许跳帧但不能倒退。
- `payout_once`: 连续输入、动画结束、信号重入场景，都不得对一次压扁结算超过一次；只有最后一脚才入账。
- `input_zones`: 鼠标在升级栏不能踩罐；鞋子的 toe/hotspot 与命中位置一致。
- `purchase`: 金币不足、条件不足、满级、重复解锁不扣款；正当购买只扣一次钱，升级立刻生效。
- `spawn`: 未解锁时只有红；蓝解锁后生成；金解锁后生成；随机种子模拟10000次结果接近配置概率。
- `auto_line`: 自动机未解锁不运行；购买后独立完成，每4秒加按`value`计算的红罐收益；升级间隔变为2.4秒，传送带×0.75；不更改主罐HP。
- `save`: 等级和解锁标志一同保存；腐坏存档不崩溃；Reset正确清空；暂停不推进计时；不发放离线金币。
- `performance`: 连续运行10分钟后节点数/VFX对象数不持续增长，无卡顿明显恶化。

## 手工流程（录屏与截图）
1. 启动：初始金币0、总数0、只有红罐、左侧商品按门槛正确锁定。
2. 把鼠标移动到车库中心：鞋光标出现，普通箭头隐藏；移到商店恢复箭头。
3. 悬停罐：无点击持续踩击，罐子每次明显凹陷。鼠标移开停止，接着移回继续。
4. 购买脚力1：红罐由3脚变2脚；脚力2：1脚。金币扣除与奖励入账时机正确。
5. 解锁蓝罐和稀有金罐后检查出现、形态、奖励、声音反馈。
6. 解锁 Auto Stomper 后在 UI 区停留20秒，保证自动产出而无需移动鞋光标。
7. 自动升级、传送带改变间隔与表现，不能多线程重复结算。
8. 保存退出、再打开、暂停、重置、600秒试玩总结与继续游玩全部正确。

## 10分钟体验测试记录
- 第一次罐压扁花了多少秒？
- 第一次购买升级花了多少秒？
- 蓝罐/金罐/自动设备/传送带解锁时间？
- 玩家是否理解光标是鞋子？
- 玩家有没有误以为必须疯狂点击？
- 玩家希望继续玩下去吗？原因是什么？
- 玩家在第几分钟明显觉得重复？

不要把`tools/simulate_balance.py`模拟的时间直接解释为真人体验结论。
