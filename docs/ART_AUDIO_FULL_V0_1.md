# 长期版美术、动效与声音规范 v0.1

> 本文件是未来《垃圾王 / 废品飞升》的美术音效提案。当前 Can Stomper v1.1 的视觉事实与贴图导入规则优先参考 docs/ART_GUIDE.md 和 AGENTS.md。

## 1. 美术定位

**废土车库像素 × 机械朋克 × 荒诞轻喜剧**。场景略脏旧、主角逐渐改造，打击特效高对比但不过度屏闪。反差由“微小的罐子”一路扩大到“压缩汽车残骸/空间核心”。避免严肃血腥、残疾猎奇、过暗导致难以识别交互对象。
配色建议：深灰 #252B30、钢蓝 #657A85、锈橙 #DD954D、能量蓝 #73D4E8、异界紫 #AC69D3；金色专用于稀有/高价值提示。角色、道具背景明度分层，交互热点清晰。

## 2. 技术基线与分辨率

**实际 Godot 工程：1280×720 设计视口、现有左侧商店+右侧固定车库、像素 nearest 导入。不得因本文改成 640×360。**
未来可测试用 640×360 作为低分辨率像素作画基准，再整数倍放大到现有 UI 视口；但需确保中文字体、鼠标热点、UI 与不同屏幕缩放清晰，验证前不改工程窗口设置。
工具：LibreSprite/Aseprite 制作角色和道具、Krita 做插画、Audacity 混音，资源均需原创或有可商用许可。禁止直接提取参考商业游戏的美术/音乐。

## 3. 场景阶段与镜头

全程复用固定可交互舞台的主要坐标，章节仅通过环境层增量叠加：
1. 铁皮仓库：旧轮胎、漏水、破旧灯；
2. 修理厂：焊机、工作台、置物架；
3. 小型回收线：皮带、收料盒、机械抓手；
4. 工业工厂：机械臂、吊车背景、工业灯；
5. 科幻基地：能量管道、空间裂缝。
目前原型是轻像素车库、俯视微倾斜、左侧升级栏和鞋光标。未来完整人物演出的机位若与此冲突，先做构图试验，再决定是否重构。

## 4. 模块化角色与资产规格（未来）

角色提议拆为头部/躯干/腿部/左义肢/右义肢/特效挂点；不可把义肢焊死在所有动作帧中。角色常见表现高度约 64–80 画面像素；小垃圾 16–32、中 32–64、大 64–128，只作为统一像素密度起点，不是直接拉伸所有物品。
动作初估：待机 4 帧；脚踩 4–6；机械拳击 4；锤击 5–6；电钻 3–4 循环；液压 5–6；激光 3 循环配独立光束；重要升级 6–8。
当前游戏没有完整人物，不应因为本文制作角色后自动删除鞋子光标。可先将可见角色只用于改造所、过场、菜单。

## 5. 垃圾与打击反馈

每垃圾尽量用一张主图 + 可复用裂纹/凹陷覆盖 + 按材质抽取的碎片 + 结算特效。旧罐已有红蓝金各 5 个真实状态帧，继续保留。
命中反馈建议：轻震屏 1–2px，重击 3–4px；普通 20–30ms 轻微击中顿感，重击 40–60ms（高频工具禁用逐击停帧）；普通碎片 4–8、重大击毁 12–20，金钱提示停留约 0.6–1s，稀有提示 1.5–2s。这些都是可调参数，不得作为实际实现宣称。
效果需要限制屏闪、粒子数、重复弹字、打击声音；提供减弱特效选项。罐堆过密不能以无提示删罐来改善性能。

## 7. BGM 方案

风格：Lo-fi 机械电子、Breakbeat、工业 Funk、轻 8-bit 合成器。避免背景音乐长期高压、过度刺耳。
- 第一章 85–95 BPM：落魄但诙谐；
- 第二章 110–120 BPM：机械动力；
- 第三章 120–130 BPM：流水线律动；
- 第四章 125–140 BPM：重工业加速；
- 第五章 100–135 BPM：空间与异界。
Demo 一首可循环曲 + 狂拆叠层即可。完整目标：1 菜单、4–5 章节、1 结局、1 爆发变奏；均不强制立即生产。

## 8. 音效清单与实现

| 分类 | 声音 | 实现建议 |
| --- | --- | --- |
| 脚踩 | 铝罐变形、塑料压缩 | 各 2–3 轻微变体，随机音高 ±5% |
| 机械拳/锤 | 驱动器 + 冲击低频 | 区分轻击/重击的层级 |
| 电钻 | 马达连续层 + 周期接触声 | 限流击中声，不按伤害帧重复 |
| 液压 | 气压释放 + 冲压 | 大型击毁时低频增强 |
| 激光/引力 | 稳定能量声 + 小型触发音 | 限制高频尖锐声 |
| 经济 | 金币、稀有掉落、购买、失败 | 使用不同长度和音高 |
| 环境与 UI | 传送开合、事件警报、菜单 | UI 音量独立可调 |

Godot 音频总线建议 Master、Music、SFX、UI；连续工具用循环流+较低频率的命中瞬态，播放数量有上限。设置至少包含总音量、音乐、音效、UI、减弱屏闪/震屏。素材清单附来源、作者、商用许可、是否署名；不能直接使用其他商业游戏的音频。
