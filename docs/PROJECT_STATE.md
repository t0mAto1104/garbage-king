## 当前认可的需求

- Godot **4.7.2 Standard**，GDScript，纯 2D；默认 1280×720、固定车库视角、左侧商店。
- 鼠标是鞋子，鞋尖命中任意地面罐后悬停连踩；点击与悬停共用冷却。空格是替代操作。
- 初始传送带每 **1.00 秒**供一罐，离带下落、弹跳、旋转滚动、随机停稳。未踩扁的罐子持续积累。
- 供罐升级间隔为 **1.00 → 0.80 → 0.60 → 0.40 → 0.25 秒/罐**。
- 每罐有独立序号、HP 和压扁状态；只有首次压扁才结算。红、蓝、金罐各有五帧。
- 独立自动回收线生产自己的罐子，不代踩或删除场内罐堆。
- v2 存档保存完整罐堆、受损和运动状态、供罐周期，兼容 v1 经济存档；不补离线收益。
- 暂停/失焦暂停；减弱特效、静音、确认重置；600 秒总结可关闭后继续。
- UI 避免非必要 secondary labels 和 descriptions。保留功能性数量、价格、等级、速度、HP 和门槛，让布局解释用途。

## 接口与代码地图

| 路径 | 职责/契约 |
| --- | --- |
| `project.godot`, `scenes/main.tscn` | Godot 入口；不随意更改应用名与存档目录 |
| `data/demo_balance.json` | 价格、伤害、收益、概率、间隔和门槛的唯一运行时来源 |
| `scripts/data_loader.gd` | 配置读取与错误校验 |
| `scripts/game_state.gd` | 经济、购买、解锁、奖励、总结和快照；纯状态与表现分离 |
| `scripts/can_field.gd` | 固定步长伪物理、供罐、堆积、命中与整个场地的保存/恢复 |
| `scripts/economy.gd` | 伤害、冷却、收益、自动/供罐间隔与压扁阶段 |
| `scripts/garage.gd` | 场地统一绘制、鞋尖光标、动效；不为每个罐子创建 Node |
| `scripts/main.gd` | UI、输入、音效、暂停与保存；`--test-mode` 隔离玩家存档 |
| `scripts/save_service.gd` | 原子写入 `user://save_v1.json`，内容 schema version=2 |
| `tests/test_*.gd` | 核心、供罐、场景、成长测试；含模拟时间检查 |

关键接口：`StompState.stomp(serial=-1)` 返回是否成功；`hit(can, payout)` 中 `can` 是所选罐字典。
`StompCanField.at_point(point)` 通过真实位置与旋转选择一罐；不能退回固定中心命中。
存档与接口改变必须在交接的 `contracts` 中说明兼容性、迁移和验证。
