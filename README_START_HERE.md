# Can Stomper（踩扁它！）10分钟可玩 Demo — Codex 开发包

## 目标
这是一个 **让真实玩家体验约10分钟** 的单人 2D 像素风增量游戏原型，**不是用10分钟开发完**。Codex 须编写可实际运行的 Godot 4.7.2 Standard + GDScript 工程，不能只交付文本、截图或独立 HTML。

核心玩法：鼠标本身是鞋子 -> 悬停持续踩踏 -> 罐子5阶段视觉压扁 -> 金币 -> 购买升级 -> 解锁新罐 -> 解锁独立自动踩踏和传送带。

## 使用步骤
1. 将此包解压到你的新项目文件夹。该文件夹作为 Codex 的 workspace。
2. 给 Codex 粘贴 `CODEX_MASTER_PROMPT.md` 全文，或直接让它阅读这个文件。
3. 先完成 `docs/PHASES.md` 中的 P0 与 P1 并亲自运行，后续逐阶段验收。
4. 游戏代码必须读取 `data/demo_balance.json`，所有经济数字集中在此文件。
5. `assets/placeholders` 是首版可直接放进场景的自制低分辨率 PNG 占位素材。`assets/references` 是概念方向板，不是可直接切图导入的 spritesheet；如需美术细化，可以后续替换占位素材。

## 项目根目录约定
Codex 在当前目录创建：`project.godot`, `scenes/`, `scripts/`, `tests/`, `README_RUN.md`。

## 范围严格限制
不做：3D、Blender、人物身体、复杂物理模拟、联网、服务器、充值、转生、多个地图、随机广告、账户、云存档、多语言完整翻译、复杂技能树。即便有多余时间也不要自行扩展。

## 验证标准
- Windows / macOS Godot Standard 本地运行，默认 1280×720，窗口缩放不破坏界面。
- 不显示独立角色或腿；鼠标进入游玩区时鞋子指针跟随，UI 区恢复普通光标。
- 固定水泥地/车库背景，左侧升级栏与中央主交互区。
- 三种罐子、5个压扁视觉阶段、4条属性/设备升级、4个功能解锁。
- 玩家约10分钟能够体会手动=>升级=>更强罐=>独立自动化=>传送带。
- 所有升级、钱数、数量、存档和自动线行为正确。
- 必须在 Godot 实际测试；如果机器没有 Godot，明说“未验证”，不能假装完成。
