# Can Stomper《踩扁它！》— 10分钟垂直切片 GDD v0.1

## 1. 产品定位
轻像素风的单屏主动增量游戏（Active Incremental），PC鼠标优先。玩家光标是鞋子，悬停踩扁地面的空饮料罐，获取金币；购买力量、速度和售价升级，开启新罐种、独立自动踩踏机、传送带。目标是展示 10 分钟内的效率跃迁，不是提供无限内容。

## 2. 画面与输入
- 固定镜头，俯视略有倾斜的像素车库水泥地面。主游戏 1280×720，左侧约 285px 资源/升级栏，余下为水泥地交互区。
- 车库背景可包含工具柜、回收箱、角落输送装置，但主操作区清晰，当前主罐绝不被大量杂物遮挡。
- 光标进入主区域时显示 **鞋子光标图**，指定鞋底前端（toe）为命中点；UI 左侧、暂停菜单等显示操作系统箭头。
- 鼠标悬停在罐子的命中区域，每到踩踏 CD 触发 stomp；离开暂停。左键点击只会在 CD ready 时触发额外 immediate stomp；不能叠加两次。空间键可在主罐存在且窗口聚焦时触发一次，作为无障碍替代。
- 不要显示玩家完整腿部、身体或第三人称角色，也不需要脚从屏幕外独立下落。

## 3. 最小循环
`当前罐生成 → 鞋子悬停/点击 → HP 下降 & 切换压扁帧 → HP=0 最终动画 → 结算一次金币 → 播放反馈 → 0.85s 后换下一罐 → 购买升级`。
- 三种罐的 HP/金币、生成概率、解锁条件详见 `data/demo_balance.json`。
- 罐子级别是类型，不是武器品级：红罐3HP/6金币、蓝罐5HP/18金币、金罐8HP/80金币。
- 升级脚力从初始1伤害开始，1级2伤害，2级3伤害，3级4伤害，依次进化。踩踏冷却默认0.68秒，速度升级降低间隔。
- 中奖奖励**只能在 HP 首次降到0时**发一次。

## 4. 伪物理动作细节
正常罐阶段：0完整、1顶部凹痕、2明显折痕、3快压平、4完全压扁。可根据累计受击比例映射视觉帧 `stage = clamp(floor(4 * (max_hp - hp) / max_hp),0,3)`，HP=0 切换到4；不同 max_hp 情况下大额伤害允许跳帧。
- 每脚画面总时长建议 0.12–0.22s，罐子短暂向横向扩张/向下压缩，迅速回弹但保留已损坏的形态；鞋光标短促踩踏反馈后恢复。
- 适度 screen shake（1–3px），小块铝片屑（<8粒每脚），全扁时更多硬币弹出（不与经济重复结算）。
- 粒子必须有寿命或对象池；避免帧率随游戏时间增长而下降。
- 像素图禁止模糊过滤。不同完整/压扁阶段必须采用实际不同形状轮廓图，不可以只有纵向缩放。

## 5. 成长系统
- `power` 脚力：LV0→LV4，每级踩击伤害+1，费用来自JSON。
- `value` 回收溢价：每级+30%金币加算，最终奖励 `round(base_coins * (1 + 0.3*level))`。
- `speed` 踩踏节奏：每级减少0.10秒CD，最低0.34秒。
- `blue_can` 解锁：压扁≥20，支付100币，蓝罐进入主生成池。
- `gold_can` 解锁：压扁≥55，支付450币，金罐低概率加入池；稀有罐要有特殊弹币表现。
- `auto_stomper`：压扁≥70，支付1200币；角落机器每4s自动完成一只红罐，收益独立计入金币与总压扁数量。UI需显示自动收入来源。
- `auto_speed`：解锁 auto 后可升级，支付1150币；间隔4s→2.4s。
- `conveyor`：压扁≥115且已开 auto，支付2300币，自动线 interval ×0.75；变化可见（更快运送+图标/动画升级）。
- 可选下一版本：多种鞋外观、更高级回收设备、转生，**Demo不要实现**。

## 6. 生成池逻辑（避免负概率）
1. 若金罐已经解锁，先以`rare_can_probability_after_unlock = 0.055`判定是否出金罐。
2. 否则或未抽中，若蓝罐已解锁，则以`blue_can_probability_after_unlock = 0.40`判定出蓝罐；其余红罐。
3. 未解锁的罐绝对不可出现。使用同一模拟种子时经济结果可复现，解锁不会影响场上已经出现的罐。

## 7. 体验节奏目标（非定时强制）
- 00:00–01:00 看懂鼠标=鞋子、第一轮压扁、脚力1/溢价1。
- 01:00–03:00 解锁加厚蓝罐，开始“更难更值钱”的选择。
- 03:00–05:00 稀有罐首次出现，积极追求自动化资金。
- 05:00–08:00 通过升级解锁独立 Auto Stomper，主游戏手动和角落自动设备同时进钱。
- 08:00–10:00 展示传送带与自动化进一步增速。**如试玩者未达到目标，仍可继续游玩，不要强制赠送升级/金币。**
- 播放满600s显示通关式“试玩总结”，不是停止场景、冻结或删除存档。

## 8. 玩家信息反馈
左栏: 币、已压扁、脚力、CD、金币倍率；Upgrades/Automation tabs；每项升级显示LV/封顶、效果、价格/不可用原因。
中央: 当前罐HP文字或压缩进度、罐类型、金币弹字、罐脚下影子。自动机画在边角，不覆盖中央交互区。
音效: 三种罐轻重不同的金属哐当声、升级、买新罐、金币落袋；有静音开关。可先生成短音频占位，不应以缺失外部音效阻碍Demo。

## 9. 存档和暂停
本地`user://save_v1.json`，包含版本，钱包、累计收入、踩扁数、各升级等级、解锁标志、游戏时间、声音/特效设置。离线收益关闭。损坏存档友善提示重置，不可以报错崩溃。每次升级、踩碎及定期自动保存。暂停后倒计时和奖励不推进。

## 10. 成功指标
- 5秒内玩家理解鞋光标能踩罐；前30秒首次买升级。
- 1分钟内体验从3脚到2脚/1脚踩扁红罐。
- 5分钟前后看到稀有罐或接近自动化。
- 10分钟内通过普通升级策略至少体验一台自动设备（需要实测）。
- 游戏无重复结算、错误扣款、无限粒子、坏档、输入冲突。
